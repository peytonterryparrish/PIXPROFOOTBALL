## What changed, per goal (user note numbers in brackets)

**1. Weight, no floating / gliding (26, 5, 13)**
- Foot splay (13): `AnimSplayFix` re-twists the legs of 24 locomotion cycles (toe-out at ground contact of the carrier forward run / sprint right foot 57 / 59 deg -> 16 / 0, plain run / sprint right foot -31 / -16 -> 10 / 18, FR / R variants 27-35 -> 7-9) + the runtime clamp. In the match view the plain forward run is now within -7 .. +12 deg at 2.5-6.5 m/s (was -18 .. -26 on the right foot) and the carry run at 4.5 m/s has the right foot 20 deg out (was 46).
- Stride: planted ball-of-foot speed (the foot that touches the ground should stand still, 0 = perfect) with the final controller: forward 3.5 m/s 0.34, 4.5 m/s 0.84, 5.5 m/s 0.81 (before the StrideTrim 0.98 / 1.18), 6.5 m/s 1.4; carry 2.5 / 4.5 m/s 0.8 / 0.5; lateral shuffle 0.4 / 0.9; back-pedal 1.2 / 1.9 / 2.3 at 1.5 / 2.5 / 3.5 m/s (open). One run of a real match view on a treadmill (`D:/PIXFootball/anim_qb/anim_qb_metrics.txt`, 2.3 s windows, 3-4 contacts per foot: +-0.3 m/s of noise).
- The pelvis bob is kept (hips y 1.05 .. 1.17 m over a sprint, root Y is not flattened anywhere); stationary poses are grounded by `FitGround` (A-010).
- Not done: start / stop / plant-and-cut clips (the plans exist in `AnimKit`; the facing loop that keeps the hips on the simulated heading cancels the turn inside those takes). Lean / bank already existed (`LeanMath`).
