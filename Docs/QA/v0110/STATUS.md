### Test fixes (5 failures on the merged tree)
- `LeagueEngineFixTests.TeamPenaltyYardsEqualThePlayerPenaltyYards` (13 against 12): root cause in `PlayerLine.HasActivity`, which ignored penalties, so a flagged bench player got no line and his flag vanished from the player totals. Fixed in `LeagueModel.cs` (one term).
- `UiFlowStatsTests.FinalScreenTeamStatsUseEnforcedPenaltyYards...`: offsetting fouls left `PenaltyYards` at -1. Now 0 (the down is replayed, nothing is enforced), `MatchFlow.cs`.
- `ContactSimTests.ForceTackleAfterKeepsDefendersOffUntilTheCarrierIsPastTheLine`: the test hook (open-field contact only) did not cover the engaged arm tackle. Hook added to `TackleResolver.ArmTackle`; the test now also ignores a runner who goes down himself (agent -1).
- `BlockingTests.RunBlockingRatingsMoveTheYardage`: the flatter tackle contest (`TackleGapScale` 0.55) narrows the spread, measured OL>>DL 5.12, even 4.75, DL>>OL 3.86 yards. Bands +0.4 -> +0.3 yards.
- `CareerDraftTests.TheDraftRunsInOrder...`: when the user picks first nobody is drafted yet (`First` threw). The "already taken" check runs only when somebody is.
- Also from the integration notes: `YardsPerCarryStayRealistic`, `NaturalPaceGivesAShortQuarterGameTheSnapsOfARealOne`, the two `Lod_*` GfxTests and the 180 s `SimCalibrationTests` case all pass on the merged tree.
