# PIX Football v0.9.0: match engine audit (448 issues)

Auditor: match-engine audit pass for the v0.9.0 "Match Engine" release. Inputs: `PLAYTEST_v080.md` (user notes 1-10), `REFERENCE_Stances.md`, `REFERENCE_AllPro2K8.md`, the code under `Scripts/Sim`, `Scripts/Gameplay/{Player,Contact,Match,Cameras,Look}`, `Scripts/Presentation`, and the v0.7 claims in `Docs/QA/v070/*.md` (verified, not trusted).

**How the numbers were produced (objective, not impressionistic).** (1) `EngineAudit` (new editor tool `Scripts/Editor/Tools/EngineAudit.cs`, flag `-pixEngineAudit`, additive, QA only) plays 48 real plays on the stadium scene through the real match stage (22 SimAgentViews, contact director, ball follower) at 60 Hz and samples every animated bone every frame: planted-foot slide per ground contact, flight phase, step rate and stride per ground speed, hips height, bone pops, clip switches, body yaw vs sim facing, ball-to-hand distance, pre-snap pose joint angles for every formation, the kicker's side and kicking foot, plus film strips. (2) A headless sim harness (`D:\PIXFootball\Renders\engine_audit\harness`, same Sim sources) ran 1,200 plays tick by tick for speeds, accelerations, heading and facing rates, action flicker, first-move latency, QB drop and release times, play length, body overlap, teleports, closing speeds, plus a body physics lab per position and an alignment sweep of every formation. (3) Five parallel code reviews (player animation, contact and match, offense sim, defense and blocking sim, special teams and graphics) cited file:line for each finding. Rows from measurement are tagged `M-n`, rows from code review `PA` (player animation view), `CM` (contact / match / camera), `SO` (offense sim), `SD` (defense / blocking sim), `SG` (special teams / graphics). About 27 duplicate review rows were merged.

Data and strips (large, not in git): `D:\PIXFootball\Renders\engine_audit\` : `motion_frames.csv` (28 MB, every agent every frame), `motion_summary.txt`, `clip_usage.txt`, `clip_switches.txt`, `pops.csv`, `stance_poses.csv`, `sim_metrics_plays.txt`, `sim_body_lab.txt`, `sim_alignment.txt`, `strips/*.png` (film strips: QB under centre / shotgun / roll-out, hand-off, run, route and catch, pass set, rush, coverage, tackle, field goal, kickoff, punt), `review/*.md` (the five raw code reviews with their verification tables). Rerun: `Unity -batchmode -projectPath <private copy> -executeMethod PixFootball.EditorTools.EngineAudit.Run -pixEngineAudit [-pixEngineAuditPlays 48] [-pixEngineAuditPhase metrics|strips|all]` (never the shared editor).

**The user's "a touch fast" note (10).** The bodies are not too fast (top speeds are at or under real in-pads values, 10-yd splits 0.1-0.2 s slow). What reads as fast is (a) the compressed event timeline (plays end in a median 2.5 s run / 3.4 s pass against 4.5 / 5.5 in the NFL, quick throws leave at 0.75-1.3 s, ball flight is flat and quick, hand-offs happen at 0.3 s), (b) the defensive line and the offensive line running like skill players, and (c) bodies that skate and float rather than step, so a given speed looks faster. See rows tagged pace in the Sim realism / Timing categories and the pace table below; proposed values are in each row and in the table.
